# CRM

> Gestión de relaciones con clientes: Contacts, Leads, Deals, Accounts, Campaigns, Tickets. Lead scoring con IA.

## `GET /zen/crm/contacts`
**Listar Contactos CRM**

Retorna todos los contactos. Soporta: limit, skip, order, where (JSON), count=1.

### Parámetros
| Nombre | In | Tipo | Requerido | Descripción |
|--------|----|------|-----------|-------------|
| `limit` | query | integer | — |  |
| `skip` | query | integer | — |  |
| `order` | query | string | — |  |
| `where` | query | string | — |  |
| `count` | query | string | — |  |

### Respuestas
- **200**: OK
- **400**: Bad Request - parámetros inválidos
- **401**: Unauthorized - falta API key, JWT o session token
- **403**: Forbidden - ACL/CLP denied
- **404**: Not Found - el recurso no existe
- **429**: Too Many Requests - rate limit exceeded
- **500**: Internal Server Error

---

## `POST /zen/crm/contacts`
**Crear Contacto CRM**

Crea un contacto. Requiere: name, email.

### Body
```json
{
  "type": "object",
  "required": [
    "name",
    "email"
  ],
  "properties": {
    "name": {
      "type": "string"
    },
    "email": {
      "type": "string"
    },
    "phone": {
      "type": "string"
    },
    "company": {
      "type": "string"
    }
  }
}
```

### Respuestas
- **201**: Created

- **403**: Forbidden - ACL/CLP denied

- **500**: Internal Server Error
