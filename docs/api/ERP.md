# ERP

> Planificación de recursos empresariales: Invoices, Products, Inventory, Orders, Employees, Payroll, Warehouses.

## `GET /zen/erp/employees`
**Listar Empleados ERP**

### Respuestas
- **200**: OK
- **400**: Bad Request - parámetros inválidos
- **401**: Unauthorized - falta API key, JWT o session token
- **403**: Forbidden - ACL/CLP denied
- **404**: Not Found - el recurso no existe
- **429**: Too Many Requests - rate limit exceeded
- **500**: Internal Server Error

## `POST /zen/erp/orders`
**Crear Orden ERP**

### Body
```json
{
  "type": "object",
  "required": [
    "type",
    "items"
  ],
  "properties": {
    "type": {
      "type": "string",
      "enum": [
        "purchase",
        "sale"
      ]
    },
    "items": {
      "type": "array"
    }
  }
}
```

### Respuestas
