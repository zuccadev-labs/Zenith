## Naming convention

`ADR-NNN-short-kebab-case-slug.md`

Examples:

- `ADR-001-folder-unification.md`
- `ADR-002-mtls-spki-pinning.md`
- `ADR-009-api-parity-closure.md`

## Lifecycle

- **Proposed:** under discussion; not yet binding.
- **Accepted:** binding; current state.
- **Deprecated:** no longer recommended, but still in use.
- **Superseded:** replaced by another ADR; link to it.
